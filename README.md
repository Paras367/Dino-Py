## ✨ Features

- 🦖 Classic endless-runner gameplay
- 🌵 Dodge obstacles and survive as long as possible
- 🐦 Flying obstacles
- 🏆 High-score tracking
- 🎨 Sprite-based graphics and animations
- 🐍 Built with Python and Pygame
- 🌐 Runs in the browser using Pygbag

## 🕹️ Controls

| Action | Key |
|---|---|
| Jump | `Space` / `↑` |
| Duck | `↓` |
| Restart | In-game restart control |

## 🛠️ Built With

- **Python** — game logic
- **Pygame CE** — graphics, input, and game mechanics
- **Pygbag** — browser compatibility
